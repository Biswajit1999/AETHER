CHAPTER 01

The rendering loop

Understand the four objects behind nearly every Three.js experience.

The mental model

Three.js is a JavaScript 3D library over browser graphics APIs. A Scene is the root of a tree; a Camera defines the view; a WebGLRenderer turns the visible scene into pixels; and a render loop repeats that work as state changes.

A mesh combines geometry (data), material (appearance), and a transform (position, rotation and scale). Keeping those responsibilities separate makes complex scenes manageable.

Coordinate compass Three.js uses a right-handed coordinate system. Cameras look down their local negative Z axis; Y is normally up.
import * as THREE from 'three';

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(60, 1, .1, 100);
const renderer = new THREE.WebGLRenderer({ antialias: true });
camera.position.z = 3;
renderer.render(scene, camera);

CHAPTER 03

Geometry, attributes and meshes

Move from primitives to data you control.

Vertices are structured data

BufferGeometry stores named attributes. Positions use three floats per vertex; normals influence lighting; UVs address textures; custom attributes can carry age, mass, phase or colour into a shader.

Reuse geometry and materials. For many copies of one form, use InstancedMesh. Dispose GPU resources when a study is removed.

Rule of scale Decide what one scene unit means. Consistent scale makes cameras, motion and lighting easier to reason about.
const count = 10_000;
const positions = new Float32Array(count * 3);
for (let i = 0; i < count; i++) {
  positions[i*3] = (Math.random()-.5)*4;
  positions[i*3+1] = (Math.random()-.5)*4;
  positions[i*3+2] = (Math.random()-.5)*4;
}
const geometry = new THREE.BufferGeometry();
geometry.setAttribute('position',
  new THREE.BufferAttribute(positions, 3));

CHAPTER 04

Cameras, light and colour

Make depth readable instead of merely present.

Compose the view

A perspective camera needs field of view, aspect, near and far clipping planes. Huge far/near ratios reduce depth precision. Update aspect and projection whenever the canvas size changes.

Lit materials need lights; MeshBasicMaterial does not. Begin with one key light and restrained ambient fill. Choose output colour space and tone mapping deliberately.

Visual diagnosis If rotation reveals a paper-thin object, the geometry is flat. Lighting cannot invent missing depth.
const camera = new THREE.PerspectiveCamera(50,1,.1,100);
scene.add(new THREE.HemisphereLight(0x8fcfff,0x08030f,1));
const key = new THREE.DirectionalLight(0xffffff,3);
key.position.set(3,4,2); scene.add(key);
renderer.outputColorSpace = THREE.SRGBColorSpace;
renderer.toneMapping = THREE.ACESFilmicToneMapping;

CHAPTER 05

Time, animation and simulation

Separate elapsed time, frame time and model time.

Frames are not seconds

requestAnimationFrame is not a guaranteed interval. Use delta for speed-independent visual motion. For sensitive models, accumulate real time and advance with a fixed step so frame rate does not change the physics.

Seeded randomness plus a fixed initial state makes a visual, thumbnail and test reproducible.

Numerical honesty State the integrator, step size, units, assumptions and limits.
let previous=performance.now(),accumulator=0;
const step=1/120;
function frame(now){
  const delta=Math.min((now-previous)/1000,.1);
  previous=now; accumulator+=delta;
  while(accumulator>=step){simulate(step);accumulator-=step;}
  renderer.render(scene,camera);
  requestAnimationFrame(frame);
}
requestAnimationFrame(frame);
CheckpointThrottle the browser and confirm the model does not accelerate.
CHAPTER 06

Interaction and spatial input

Connect pointer gestures to camera and scene.

Two kinds of control

OrbitControls supplies orbit, dolly and pan around a target. Enable damping and call update() each frame. Raycaster turns normalised pointer coordinates into a selection ray.

Keep input separate from model state. Add keyboard access, visible focus, reduced-motion support and reset.

Touch detail Test coarse pointers. Hover does not exist on a touchscreen.
const controls=new OrbitControls(camera,renderer.domElement);
controls.enableDamping=true;
const pointer=new THREE.Vector2(),raycaster=new THREE.Raycaster();
canvas.addEventListener('pointermove',e=>{
  const r=canvas.getBoundingClientRect();
  pointer.set((e.clientX-r.left)/r.width*2-1,
    -(e.clientY-r.top)/r.height*2+1);
  raycaster.setFromCamera(pointer,camera);
});

CHAPTER 07

Particle systems

Represent structure with points, not thousands of meshes.

Design the distribution first

A particle system is usually one THREE.Points backed by BufferGeometry. Meaning comes from the sampler: a sphere needs volume sampling; a galaxy needs radial density, arms and thickness; a fountain needs velocity under acceleration.

Put static properties in attributes and dynamic controls in uniforms. Updating one uniform is cheaper than rewriting every particle.

Thumbnail fidelity Generate previews from the same sampler or equation as the full scene.
const material=new THREE.PointsMaterial({
  color:0x55ddff,size:.025,transparent:true,
  depthWrite:false,blending:THREE.AdditiveBlending
});
const cloud=new THREE.Points(geometry,material);
scene.add(cloud);
geometry.attributes.position.needsUpdate=true;
CheckpointChange a uniform random radius into a density distribution.
CHAPTER 08

GLSL shaders and uniforms

Move repeated visual computation onto the GPU.

One program, many vertices

A vertex shader transforms every vertex. A fragment shader colours fragments. Attributes vary per vertex; uniforms are shared; varyings carry interpolated data between stages.

Begin with the default transform and add one deformation at a time. Keep shader text readable and enable shader checks during development.

Point sprites gl_PointCoord runs from zero to one across each point square.
// vertex shader
uniform float uTime;
void main(){
  vec3 p=position;
  p.y+=sin(p.x*4.0+uTime)*0.15;
  vec4 mv=modelViewMatrix*vec4(p,1.0);
  gl_PointSize=3.0*(2.0/-mv.z);
  gl_Position=projectionMatrix*mv;
}
// each frame
material.uniforms.uTime.value=elapsed;

CHAPTER 09

Audio-reactive graphics

Translate sound energy into controlled visual behaviour.

Build an audio graph

An AudioContext owns connected nodes. AnalyserNode exposes time and frequency samples without changing the sound. Autoplay policy means audio begins after a user gesture.

Compute bass, mid and high bands; normalise and smooth them; map each to a meaningful parameter. Keep a silent fallback.

Privacy Object URLs can play selected local files entirely inside the browser session.
const context=new AudioContext();
const source=context.createMediaElementSource(audio);
const analyser=context.createAnalyser();
analyser.fftSize=2048;
source.connect(analyser).connect(context.destination);
const bins=new Uint8Array(analyser.frequencyBinCount);
analyser.getByteFrequencyData(bins);
const bass=average(bins.slice(0,24))/255;
CheckpointAdd exponential smoothing and compare with the raw signal.
CHAPTER 10

Production, testing and release

Treat lifecycle and performance as part of the artwork.

Finish the system

Resize from display size, cap pixel ratio, lazy-load heavy studies and reduce particle counts on constrained devices. Dispose geometries, materials, textures, controls and post-processing when switching.

Test creation, resize, update, render and disposal. Run a production build, inspect browser errors, verify keyboard/mobile layouts, and compare every title, thumbnail and animation.

Release gate A beautiful frame is unfinished if it leaks memory, misstates its model or fails on mobile.
function disposeObject(root){
  root.traverse(object=>{
    object.geometry?.dispose();
    const list=Array.isArray(object.material)
      ?object.material:[object.material];
    list.filter(Boolean).forEach(m=>{
      Object.values(m).forEach(v=>v?.isTexture&&v.dispose());
      m.dispose();
    });
  });
}

ESSENTIAL FIELD NOTES

Topics that connect the chapters

Assets and scene graphs

Load textures with TextureLoader and glTF scenes with GLTFLoader. Treat loaded models as object trees: transforms on a parent group affect every descendant. Resolve URLs through the development server, provide visible loading and error states, and dispose textures when the scene is retired.

PBR, shadows and post-processing

MeshStandardMaterial responds to physically based light parameters and environment maps. Enable shadows only for lights and objects that need them. Build bloom, tone mapping and output conversion as an explicit EffectComposer pass chain; every pass costs render time.

Resize and diagnostics

Measure the canvas display rectangle, cap device pixel ratio, update the camera aspect, and resize both renderer and composer. Keep shader checks enabled in development. Inspect the console, network panel, renderer statistics and GPU frame time before changing visual code.

WebGPU and TSL

Three.js also provides an evolving WebGPU renderer and its node-based Three Shading Language. Treat this as a deliberate renderer choice, feature-detect it, retain a WebGL path where required, and follow the version-matched official examples because this surface changes faster than the core scene API.

CAPSTONE

Build an equation-driven orbit study

Choose a documented system of differential equations. State parameters and initial conditions. Integrate with fixed-step RK4, store the trajectory in BufferGeometry, add a progress attribute, and move a luminous head along it with a shader uniform. Add OrbitControls, reduced motion, deterministic preview, metadata and a numerical limitation.

  1. Research and record the equation.
  2. Test the integrator independently.
  3. Normalise only for display.
  4. Render points and a faint line.
  5. Expose visual controls.
  6. Dispose, resize and validate.
function rk4Step(state, time, h, derivative) {
  const add = (a,b,f) => a.map((v,i) => v+b[i]*f);
  const k1 = derivative(state,time);
  const k2 = derivative(add(state,k1,h/2),time+h/2);
  const k3 = derivative(add(state,k2,h/2),time+h/2);
  const k4 = derivative(add(state,k3,h),time+h);
  return state.map((v,i) =>
    v+h*(k1[i]+2*k2[i]+2*k3[i]+k4[i])/6);
}
